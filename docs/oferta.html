Automatyczne alerty medyczne

System automatycznie wykrywa nieprawidłowości i oznacza wyniki wymagające uwagi:

⚠ Anemia — HGB < 11.5 g/dL ⚠ Hiperglikemia — glukoza > 126 mg/dL ⚠ Hipoglikemia — glukoza < 70 mg/dL ⚠ Leukocytoza — WBC > 11.0 ⚠ Niedoczynność tarczycy — TSH > 4.5 ⚠ Nadczynność tarczycy — TSH < 0.4 🔴 Pilne — wykryte słowa kluczowe

Alerty wykrywane automatycznie przy każdym skanie, widoczne w panelu i opcjonalnie wysyłane emailem lub webhookiem.

Jak dostać dane do swojego systemu

🔗 REST API (JSON)

Gotowe endpointy REST — wyślij dokument, odbierz strukturalny JSON. Działa z każdym językiem programowania i platformą.

POST /v1/scan → { "HGB": 10.2, "patient": "..." }

📡 Webhook

Podaj swój URL w panelu — IKZOCR automatycznie wysyła wynik OCR do twojego systemu po każdym skanie. Zero pollingu.

POST → https://twoj-system.pl/api/wyniki

📊 Eksport CSV / Excel

Pobierz archiwum skanów jako tabelę jednym kliknięciem. Idealny dla placówek korzystających z Excela lub Arkuszy Google.

Pobierz wyniki.csv

📱 IKZ Mobile

Natywna integracja z aplikacją IKZ — wyniki OCR trafiają automatycznie jako badania do silosu zdrowotnego pacjenta.

Header: X-IKZ-Silos-Id
